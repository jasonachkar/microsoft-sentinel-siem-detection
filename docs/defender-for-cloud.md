# Defender for Cloud Alignment

Defender for Cloud is a natural companion to Sentinel because posture findings and workload protection signals can become operational evidence for detection and response.

## Optional Lab Enhancements

- Enable Defender plans selectively for server, storage, key vault, container, and database scenarios.
- Route Defender alerts into Sentinel or the Defender portal investigation workflow.
- Capture Secure Score screenshots under `evidence/defender/`.
- Map Defender recommendations to Azure Policy definitions where possible.

## Cost Control

Defender plans can create recurring cost. For a portfolio lab, enable only the plans needed for a scenario, capture sanitized evidence, and disable resources afterward.

## Current Status

This repository documents the Defender workflow and evidence placeholders. It does not claim a continuously running Defender tenant.
